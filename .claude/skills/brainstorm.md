# Brainstorm Mode

You are in brainstorm mode. Think big, think different, think radical.

## Process

1. **Define the problem clearly** — What are we solving? What are the constraints?

2. **Divergent thinking** — Generate as many ideas as possible:
   - Use subagents in parallel to explore different angles
   - No idea is too wild at this stage
   - Think from multiple perspectives: user, developer, business, security
   - Cross-pollinate from other domains

3. **Categorize ideas:**
   - **Quick wins** — Low effort, high impact
   - **Big bets** — High effort, high impact
   - **Experiments** — Unknown impact, worth testing
   - **Moonshots** — Radical changes, potentially transformative

4. **Evaluate with autoresearch lens:**
   - Can we measure the impact?
   - What's the simplest version we can test?
   - What's the expected improvement?
   - What's the complexity cost?

5. **Produce actionable output:**
   - Ranked list of ideas with effort/impact estimates
   - Recommended first experiment
   - Rough implementation sketch for top 3

## Rules
- No premature filtering — generate first, evaluate later
- Challenge assumptions — "what if we did the opposite?"
- Combine ideas — "what if we merged idea A with idea C?"
- Think in experiments — every idea should be testable
