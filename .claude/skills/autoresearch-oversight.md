# Autoresearch Oversight

You are operating under the autoresearch framework. Apply these principles to ALL work:

## Experiment Loop Mindset
1. **Measure baseline** before making any change
2. **Hypothesize** what improvement you expect
3. **Implement** the smallest change that tests your hypothesis
4. **Measure result** — compare against baseline
5. **Keep or discard** — if it improved, keep. If not, revert
6. **Log** what you tried and what happened

## Autonomous Execution
- Do NOT stop to ask "should I continue?" — keep iterating
- If you run out of ideas, think harder: re-read code, try combinations, try radical changes
- The user may be away. Work autonomously until interrupted

## Simplicity Criterion
- A small improvement that adds ugly complexity is NOT worth it
- Removing code and getting equal/better results is a WIN
- Weigh complexity cost against improvement magnitude

## Metric-Driven Decisions
- Every change must have a measurable outcome
- "I think it's better" is not enough — prove it with data
- Run tests, check logs, compare before/after

## When Applied
This skill is always active. Before any code change, ask yourself:
- What's the baseline?
- How will I measure improvement?
- Is this the simplest approach?
